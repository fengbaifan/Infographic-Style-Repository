# 信息图形的数据逻辑、视觉编码与案例研究

本仓库建立两层互相独立、可交叉检索的信息图形知识体系：

- **[01-信息图形数据逻辑](./01-信息图形数据逻辑/)**：回答“信息为什么以这种结构组织？”，研究原始数据关系、适用的统计/计算、视觉编码、信息架构及视觉叙事。包括编年型、层级型、编目型、字母表型、地理图形五种组织逻辑。
- **[02-信息图形类型案例](./02-信息图形类型案例/)**：回答“信息实际上以什么视觉形式被讲述？”，收录混合型、文字/列表型、时间轴型等表现类型及逐图案例。

**核心原则：先分析数据关系，再确定组织逻辑，最后选择可视形式；不以外观代替数据结构判断。** 五种组织逻辑与三种表现类型不是同一层的分类，一张作品可以同时具有多种组织逻辑和表现技法。

文档共同采用 A 数据逻辑、B 统计/计算方式、C 视觉编码、D 数据/信息架构、E 视觉叙事架构，附判别条件、反例及交叉链接。理论文档不放案例图片，仅通过相对 Markdown 链接引用 02 内的案例索引或已核实案例。

## 案例驱动更新

新增案例时，先确认能直接查看原图，再建立独立的逐图分析记录，提取证据及可迁移原则；将已证实的规律反馈到对应类型说明和 01 的底层逻辑文档。缺少原图或元数据的案例不编造来源、数值、视觉细节。查看 [案例录入与回写规范](./02-信息图形类型案例/案例录入与知识回写规范.md)。
