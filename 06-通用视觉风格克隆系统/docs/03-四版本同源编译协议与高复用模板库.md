# 03 · 四版本同源编译协议与高复用模板库

本文档是 SC-PRO 系统的**第三引擎规范（输出编译与验收层）**，确保每次提取或迁移都能从同一个风格数据源零损耗编译出 **4 个各司其职、100% 支持填空复用的提示词版本**。

---

## 一、为什么要同源输出 4 个版本？

没有任何单一格式的提示词能通吃今天所有的 AI 图像工具：
- 连续自然语言在 **GPT Image 2.0 / Nano Banana / FLUX** 上空间叙事极准，但在 **即梦（SeedDream）/ 通义万相** 上写超过 200 字就会稀释前排核心词权重；
- 短词堆砌在即梦上出图干脆，但丢失了复杂的叙事张力与多图单变量可调性；
- 结构化 JSON 是最完美的**人类设计主权面板与资产存档格式**，便于单字段手术式修改与跨 LLM 工作流传递。

因此，SC-PRO 采用 **「1 份双核数据母本 → 4 版本同源同步编译」**，且**强制要求全部 4 个版本都具备显式物理分区（锁死风格区 vs 可替换主题槽）**，确保任何一个版本单独拿出去都能直接改主题复用！

---

## 二、四版本编译细则与权重排版律

### 1️⃣ 版本一：中文结构化 JSON 提示词 (`zh_json`)
- **核心作用**：设计师可读性最高的总控面板、飞书/Notion 个人风格库标准存档、国内大模型（DeepSeek / 豆包 / Kimi）二次批量生成脚本的输入源。
- **编译规则**：
  1. 严格包含 `"元数据"`、`"风格基因锁死区"`、`"主题自适应转译桥"`、`"主题可变插槽区"` 四大顶层键；
  2. 合法 JSON 语法（双引号闭合、无尾随逗号），可直接被代码或工作流节点 `JSON.parse()` 解析；
  3. `"风格一致性五锚点"` 必须浓缩为 5 条高辨识度铁律，作为人工核验清单。

### 2️⃣ 版本二：英文结构化 JSON 提示词 (`en_json`)
- **核心作用**：跨国 AIGC 管线（ComfyUI API 节点、Nano Banana、Midjourney、FLUX）高精度语义底座。
- **编译规则**：
  1. 与中文 JSON **键名层级 1:1 严格对齐**，绝不允许中英两版出现颜色、比例、数量或排除项不一致；
  2. 严禁机械字面直译！必须使用英文艺术史与计算机图形学原生术语（例如中文写“水墨飞白与宣纸渗化”，英文编译为 `expressive dry-brush feibai flying-white strokes and organic sumi-ink capillary bleeding on raw xuan paper`，而非生硬的 `ink white flying`）。

### 3️⃣ 版本三：中文简易提示词 (`zh_concise`)
- **核心作用**：面向即梦（SeedDream 4.0/5.0）、通义万相、可灵、星流、LiblibAI 等中文关键词驱动平台的一键直出高权重短指令。
- **字数硬约束**：正文控制在 **90–140 个汉字**（黄金高响应区间，防止后半段肌理与色调词被截断或降权）。
- **词序权重编译公式（越靠前权重越高）**：
  ```text
  【主题槽：核心主体 + 状态动作 + 极简场景 + 焦点细节】，[媒介与流派核心词]，[造型线质与边缘特征]，[主辅色调配比 + 阴影色相偏移]，[光线方向光质与光比]，[构图重心 + 留白比例 + 张力对比]，[核心物理肌理词]，[无违和渲染词1、无违和渲染词2]，[画幅比例]
  ```
- **双态同步交付（保障 100% 复用性）**：
  - 每次输出版本三时，必须上下并列提供两行：
    1. **`[通用填空母版]`**：保留 `【主题槽：{{核心主体}}，{{动作状态}}，置于{{场景}}】`，后面紧跟完全锁死的风格短语链——用户收藏这一行，以后换 100 个主题只需改第一个中括号！
    2. **`[即用成品提示词]`**：去掉所有花括号标记、已完成新主题色域与材质转译的干净纯文本，复制粘贴即刻出图。

### 4️⃣ 版本四：模块化自然语言提示词 (`natural_language` · 4A 中文 + 4B 英文)
- **核心作用**：面向 GPT Image 2.0、Nano Banana（Google Gemini 图像）、FLUX.1/2、Lovart、Midjourney V7/V8 等强自然语言理解后端，最大化释放空间关系动词与光影叙事细腻度。
- **三段式物理隔离协议（解决自然语言无法复用的顽疾）**：
  - **禁止把风格修饰词和主体内容混写在同一段落中交叉缠绕！** 必须切分为职责纯净的三段：
    - **`[P1 风格宪章段 · 固定复用]`**（约 50–70 词）：声明艺术媒介坐标、叙事基调、造型线质/体块机制、三级边缘控制、完成度分配、基底肌理与独特视觉异常。**（换主题时一字不改！）**
    - **`[P2 主题叙事槽 · 换主题仅改此段]`**（约 50–80 词）：以 `【...】`（中文）或 `[[...]]`（英文）显式包裹——描述经过自适应转译后的主体、状态动作、环境场域、两极张力对话关系、视线引导路径、停留锚点及可选版式文案。**（换主题时只替换这一段！）**
    - **`[P3 光色空间与禁令 · 固定复用]`**（约 50–70 词）：声明构图景别与留白节奏、主辅强调色彩体系、高光与阴影色相偏移、光源逻辑、画幅比例及 `without / no ...` 负向排除护栏。**（换主题时仅按需改画幅数字，其余一字不改！）**
  - *生图投喂提示*：实际粘贴进生图框时，可去掉 `[P1...]` 标题标签，将三段合并为一段连贯文本直接提交。

## 四、六维验收清单与单变量手术式修订闭环

生成图像后，拒绝凭“好不好看”主观判断，对照 JSON 逐项执行 **6 维验收**：

1. **防污染核验**：画面里是否混入了 `原图剥离黑名单` 里的旧器物、旧人物或旧背景？（出现即 `FAIL`，需强化负向护栏并检查是否垫图权重过高）。
2. **五锚点保持度**：`风格一致性五锚点`（线质、色彩与阴影色偏、光线逻辑、空间留白、基底肌理）是否全部在场？有没有滑向大模型默认的“平滑数码厚涂/写实摄影”？
3. **自适应融合度**：新主题的固有色与材质是否已融进原风格媒介，还是像一张格格不入的贴纸贴在背景上？
4. **叙事与张力有效度**：拉远画面 **3 秒自测**——第一眼视觉入口清晰吗？两极张力成立吗？停留点细节接得住目光吗？
5. **图文与版式准确度**（若含文字）：字形有无错漏笔画？文字是融入了画面肌理，还是生硬浮在表面？
6. **系列连续性**（若为 `EXPAND` 模式）：多张图并排观看时，阴影色温、笔触粗细与主角面部记忆点是否出自同一宇宙？

### 单变量手术式修订铁律（Single-Variable Surgical Revision）
当某一项未通过验收时：
- ❌ **绝对禁止**：凭感觉把整段提示词推倒重写，或盲目狂加“大师杰作、极致细节、8K”等废词。
- ✅ **标准动作**：回到【版本 1/2 JSON】，定位唯一失准的字段（例如：发现AI把边缘画得太硬 → 仅修改 `C2_三级边缘控制` 与 `C4_媒介肌理` 增加湿画晕染描述，**冻结其余 11 个分系统一字不动**）→ 重新同步编译受影响的那一句 → 再次生图验证。
