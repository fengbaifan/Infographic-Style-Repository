# SC-PRO 通用结构化视觉风格克隆与自适应编译系统 (v2.0)

> **一句话定位**：精确逆向提取任意参考图的「视觉生成规则与关系基因」，彻底剥离原图表面内容污染，支持**跨题材主题变更、同系列主题扩展、跨品类风格迁移**，并同源编译输出 **100% 可复用的 4 版本提示词（中文 JSON / 英文 JSON / 中文简易词 / 中英模块化自然语言）**。

---

## 一、三大使用场景快速启动指南

本系统针对你的三种真实工作方式做了专门的工程封装，按需选择对应入口即可：

### 场景 1：直接拖入网页版大模型启动（零配置即插即用）
- **使用文件**：[SC-PRO_单文件全能运行版(拖入网页端即用).md](./SC-PRO_单文件全能运行版(拖入网页端即用).md)
- **操作步骤**：
  1. 打开任意网页版多模态大模型（ChatGPT / Claude / Gemini / 豆包 / Kimi / DeepSeek 等）；
  2. 将上述**单文件**直接拖入对话框（可同时拖入你要提取的风格参考图）；
  3. 发送口令：**`启动风格分析和克隆系统`**（或直接附带任务，如：`启动风格分析和克隆系统，提取这张图的通用风格，并迁移到“现代精品手冲咖啡壶海报”主题`）。
- **效果**：单文件已内置完整的 `[SYSTEM BOOTLOADER]` 引导头、13 分系统提取器、四大自适应转译法则与四版本编译器，无需加载任何其他文件即可完整运行。

---

### 场景 2：从仓库启动阅读与协作（IDE / Agent / 本地知识库模式）
- **适用环境**：在 Antigravity、Cursor、Claude Code、Obsidian 或知识库工具中打开本目录。
- **自动路由**：AI 助手会自动读取根目录下的 [AGENTS.md](./AGENTS.md) 协议，按任务类型渐进加载 `docs/` 下的专项深层词典，并将为你提取的风格永久沉淀到 `style_library/` 风格资产库中。
- **人工深读导航**：
  1. [01-精准风格提取与13分系统参数词典.md](./docs/01-精准风格提取与13分系统参数词典.md) —— 怎么把一张图拆成精确参数？内置光线/色温/阴影色偏/线质/边缘/材质/七大张力完整中英词表。
  2. [02-通用双核JSON架构与主题自适应迁移引擎.md](./docs/02-通用双核JSON架构与主题自适应迁移引擎.md) —— 为什么换主题不会破风？详解全品类通用插槽与【变更 / 扩展 / 迁移】自适应四法则。
  3. [03-四版本同源编译协议与高复用模板库.md](./docs/03-四版本同源编译协议与高复用模板库.md) —— 四个版本提示词如何保证同源一致与填空级复用？附各大生图模型（即梦 / Nano Banana / GPT Image / MJ / FLUX）投喂策略。
  4. [04-全链路实战基准样板(提取→通用母版→跨界迁移4版本).md](./docs/04-全链路实战基准样板(提取→通用母版→跨界迁移4版本).md) —— 完整端到端输出样板示范，直观查看提取母版、跨界换主题、跨品类做海报的四版本真实交付效果。
  5. [05-与信息图形知识库(01-05及99)的联动协议.md](./docs/05-与信息图形知识库(01-05及99)的联动协议.md) —— 定义本系统与 `01/04` 数据逻辑与统计图表、`02` 案例库、`03` ISOTYPE、`05` Gestalt 及 `99` 主题工作流的跨系统联动机制与数据真实性边界。

### 场景 3：大模型形成长期记忆后直接调用（免传文件极速调用）
- **使用文件**：[01-大模型长期记忆注入包(Memory与自定义指令版).md](./memory/01-大模型长期记忆注入包(Memory与自定义指令版).md)
- **操作步骤**：
  1. 打开该文件，复制其中的 **「一键记忆固化指令」** 发给支持长期记忆的大模型（或将其中的 **「超浓缩内核 / 智能体指令版」** 粘贴进 ChatGPT Custom Instructions、Claude Project、Gemini Gem、豆包智能体）；
  2. 模型确认记住后，今后新开任何对话**无需再上传文档**，直接发图并输入极简口令（如 `【风格提取】`、`【主题变更：新主题】`、`【主题扩展 x4：方向】`、`【跨品类迁移：目标品类】`）即可直接吐出标准 4 版本可复用提示词！

## 三、常用操作口令速查卡

无论在哪种场景下启动系统后，你都可以用最自然的话术下达以下五种核心指令：

| 你想做的事 | 直接发送的指令示例 | 系统交付结果 |
| :--- | :--- | :--- |
| **1. 纯提取通用风格** | `提取这张图的风格，生成通用提示词母版` | 剥离原图内容 + 输出带 `{{变量槽}}` 的 **4 版本通用风格母版**（永久复用） |
| **2. 换主题不换风格** | `用刚才的风格（或此参考图风格），主题变更为：[现代无线耳机产品静物]` | 自动执行色域投影与材质转译 + 输出适配新主题的 **4 版本可复用提示词** |
| **3. 同风格系列扩展** | `沿用该风格，围绕[二十四节气·冬]扩展 4 张系列画面` | 锁定五锚点与系列资产 + 按叙事弧线输出 4 张分画面结构与提示词 |
| **4. 跨品类风格迁移** | `把这张插画的风格迁移到[汉字“破”字主题海报]上` | 保留媒介肌理、色光与张力基因，重构为字体/海报空间语法并输出 **4 版本提示词** |
| **5. 出图后局部微调** | `刚生成的图阴影太黑、背景太满，按单变量微调` | 冻结其余全部参数，仅修正 `色彩语法(阴影色偏)` 与 `信息密度` 并同步更新 4 版本 |
