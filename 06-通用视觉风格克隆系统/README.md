# 06｜通用视觉风格克隆系统

精确提取参考图的视觉风格生成规则，剥离原图内容，支持**风格迁移、主题扩展、主题变更不破风**，并同源输出**可复用的 4 个版本提示词**（中文 JSON / 英文 JSON / 中文简易词 / 自然语言提示词）。

## 目录

- [风格克隆系统.md](./风格克隆系统.md) —— 核心运行文件（**场景 1 拖入网页大模型** 与 **场景 2 从仓库阅读** 共用）
- [记忆指令.md](./记忆指令.md) —— **场景 3 专用**：喂给大模型写入长期记忆，以后免传文件直接口令调用
- [风格库/](./风格库/README.md) —— 存放以后提取并验证好的可复用风格档案

## 三种用法

1. **拖入网页大模型**：直接把 [风格克隆系统.md](./风格克隆系统.md) 拖进对话框（可附参考图），发送 `启动风格分析和克隆系统`。
2. **从仓库启动阅读**：在本地 IDE / AI 助手中直接读取 [风格克隆系统.md](./风格克隆系统.md) 即可运行，提取结果存入 `风格库/`。
3. **形成记忆后调用**：复制 [记忆指令.md](./记忆指令.md) 中的指令发给大模型记住，之后新开对话直接发图+口令调用。

## 与本仓库的关系（两句话）

- **进**：可直接从 [02-信息图形类型案例](../02-信息图形类型案例/README.md) 里挑选喜欢的案例原图来提取纯视觉风格（仅提语法，不搬数据与内容）。
- **出**：在做 [99-XXX主题信息图形设计](../99-XXX主题信息图形设计/README.md) 的视觉编码与设计阶段时，直接调用本目录的风格档案来统一画风；**底线：视觉风格只管表现层统一，绝不篡改数据、比例尺与信息准确度。**
