# 记忆指令（场景 3：大模型记住后零附件直接调用）

把下方【步骤一】复制发给支持长期记忆的大模型（ChatGPT Memory / Gemini / 豆包 / Kimi 等），或直接粘贴进 **自定义指令（Custom Instructions）/ Gem / Project / 智能体设定**。记住后，新开对话无需再拖文件，直接发图 + 【步骤二】里的短口令即可运行。

---

## 步骤一：一键写入记忆指令（直接整段复制发送）

```text
请将以下【通用视觉风格克隆系统】规则写入你的长期记忆。今后只要我说“启动风格分析和克隆系统”、“提取风格”、“主题变更”、“主题扩展”或“风格迁移”，立即按此标准执行，不再需要我重传文档：

1. 去内容剥离：分析参考图先列“原图剥离黑名单”（剔除原图人物/器物/场景/文字），严禁流入风格层；禁用“唯美/高级/大气/复古”等模糊情绪词，全转为精确视觉语法参数。
2. 13项精准提取：提取媒介流派、一句话叙事立场、独特视觉异常；色彩配比与高光/阴影色相偏移；光线方向/软硬/光比/色温；构图路径/留白比例/尺度；线质造型/三级边缘/完成度分配/基底肌理；信息密度/视觉锚点/主导张力；锁定【风格一致性五锚点】与【负向防漂移护栏】。
3. 通用双核结构：全品类通用（人物/产品静物/建筑风景/海报/字体），把“风格锁死区”和“主题可变区”彻底分开。未给新主题时，可变区填 `{{核心主体}}` 等占位符输出通用提示词母版。
4. 换主题自适应四规则（变更/扩展/迁移不破风）：①新物体固有色降维投影进原风格色域；②新材质转译为原媒介笔触画法（禁混入3D写实反射）；③继承原疏密留白关系而非死搬坐标；④细节重心随主体品类切换。若用于信息图形，风格不改数据与比例尺。
5. 每次必须同源输出 4 个高复用版本：
   - 版本1：中文双核 JSON（风格锁死区 + 主题可变区）；
   - 版本2：英文双核 JSON（与中文1:1对齐，英文高精度视觉语法词）；
   - 版本3：中文简易提示词（90-140字，“【主题槽：{{...}}】，[固定风格核]，[固定肌理与无xxx禁令+画幅]”，给母版+去括号成品版）；
   - 版本4：自然语言提示词（含中文+英文，严分三段：[P1风格宪章·不变] + [P2主题叙事·换主题仅改此段] + [P3光色空间与禁令·不变]）。
6. 默认只输出诊断卡和 4 版本提示词，仅当我明确要求“直接出图”时才生成图像。

请记住上述规则，并用 3 句话确认就绪。
```

## 步骤二：形成记忆后的常用短口令

- **纯提取通用风格母版**：`启动风格分析和克隆系统：提取附图风格，给我带槽位的 4 版本通用提示词母版。`
- **换主题不换风格（主题变更）**：`用附图（或刚才的）风格，主题变更为「现代黄铜摩卡咖啡壶静物，4:3横版」，输出 4 版本提示词。`
- **同风格出系列图（主题扩展）**：`沿用当前风格，围绕「二十四节气·冬」扩展 4 张系列画面，先列分画面方案，再输出第 1 张 4 版本提示词。`
- **跨品类风格迁移**：`把附图画风迁移到「汉字“山”主题文化展览竖版海报（2:3）」上，输出 4 版本提示词。`
- **单变量微调**：`刚出图暗部太死黑，保持其余所有参数不变，只微调阴影色偏并同步更新 4 版本。`
