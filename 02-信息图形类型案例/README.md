## 每个标签统一采用
```text
02-信息图形类型案例/
└── 标签目录/
    ├── 00-标签说明.md
    └── 案例/
        ├── README.md
        ├── CASE-0001-作品名/
        │   ├── 原图.png
        │   └── 分析.md
        └── CASE-0002-作品名/
            ├── 原图.jpg
            └── 分析.md
```
示意 CASE 目录**不代表已上传案例**。每有一张原图才建立一个实际 CASE 子目录；允许多个案例，不限两个。独立原图与其分析必须存放在同一 CASE 中。
